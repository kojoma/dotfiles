# AI エージェント共通指示

Claude、Codex などの AI エージェントは、作業内容に応じて `rules/` 以下の関連するルールを参照してください。

このディレクトリには、環境固有、仕事固有、個人固有の情報を追加しません。共有可能な一般ルールだけを扱います。

## 共通ルールの更新

作業中に新しい一般ルールを発見した場合は、次のすべてを満たすときに `rules/` の適切なファイルへ追記する変更を作成します。

- 複数の環境やプロジェクトで再利用できる内容である。
- 仕事固有、環境固有、個人固有の情報や秘密情報を含まない。
- 既存のルールと重複または矛盾しない。

ルールは具体的かつ簡潔に記述し、必要なら適用条件や例外も記載します。変更は `rules/git.md` の GitHub Flow に従い、専用ブランチでコミットして Pull Request として提案します。PR の Description には、追加理由と適用範囲を記載します。
